# Changelog

Все заметные изменения проекта PenguinCraft.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.3.0] — 2026-10-19

### Добавлено

- **Поддержка Windows** — лаунчер полноценно работает под Windows 10/11:
  - каталог данных — `%LOCALAPPDATA%\PenguinCraft` (специально не роуминг-
    профиль: библиотеки и ресурсы игры весят гигабайты);
  - поиск уже установленной Java в привычных местах (`Program Files\Java`,
    `Eclipse Adoptium`, `Microsoft`, `Zulu`, `Amazon Corretto`,
    `%LOCALAPPDATA%\Programs`) с учётом `java.exe`;
  - авто-загрузка JRE с Adoptium под Windows берёт `zip`-архив;
  - авто-подбор объёма памяти через `GlobalMemoryStatusEx`;
  - корректный разбор аргументов JVM и игры с обратными слэшами
    (`C:\Java\jdk-21`) и запуск процесса без POSIX-специфичных флагов.
- **Переносимый `.exe` и установщик** — собираются на Windows командой
  `python packaging\windows\build.py` (PyInstaller + Inno Setup):
  - `PenguinCraft-<версия>-setup.exe` — установщик в профиль пользователя
    (без прав администратора), с ярлыками в меню «Пуск» и удалением;
  - `PenguinCraft-<версия>-portable.exe` — один файл, ничего не
    устанавливает.
- Безопасные имена экземпляров с учётом ограничений Windows: недопустимые
  символы, зарезервированные устройства (`CON`, `NUL`, `COM1`…),
  завершающие точки и пробелы.
- Отдельный workflow GitHub Actions: автотесты под Windows и сборка `.exe`;
  по тегу файлы автоматически прикладываются к релизу.

## [1.2.0] — 2026-10-19

### Добавлено

- **Зависимости модов** — лаунчер читает метаданные (Fabric, Quilt, Forge,
  NeoForge) и при установке мода сам подтягивает обязательные зависимости
  с Modrinth (рекурсивно, с защитой от циклов). Переключатель «ставить
  зависимости» есть на странице «Моды» и в настройках.
- **Проверка зависимостей** — отдельная кнопка ищет моды, у которых нет
  обязательной библиотеки, зависимости выключены, конфликты по
  `incompatible` и моды «чужого» загрузчика.
- **Проверка целостности** — сверка клиента, библиотек и ресурсов с
  манифестом Mojang (по размеру, а в глубоком режиме — по sha1) и
  восстановление повреждённых файлов. Доступно из интерфейса и командой
  `verify --repair`.
- **Сопоставление вручную поставленных модов** — лаунчер находит мод на
  Modrinth по sha1 файла, после чего для него тоже работают проверка и
  установка обновлений.
- **Автообновление модов** — фоновая проверка обновлений при запуске
  лаунчера с настраиваемым интервалом. Игру не блокирует.
- **Управление мирами** — отдельное окно со списком миров: размер, дата
  изменения, экспорт и импорт `.zip`, удаление и резервная копия всех
  миров сразу.
- **Настройки экземпляра** — окно с памятью, профилем JVM, аргументами,
  путём к Java, разрешением, полноэкранным режимом и заметками.
- **Просмотр отчётов о падении** — прямо в лаунчере, с копированием и
  открытием папки.
- **Проверка обновлений лаунчера** — через GitHub Releases, с напоминанием
  при запуске (отключается в настройках).
- **Масштаб интерфейса** — 100–200 % для HiDPI-экранов.
- **Сортировка и «Показать ещё»** в поиске модов и модпаков.
- **Автотесты и CI** — 140+ тестов на `unittest` (без сети и графики) и
  workflow GitHub Actions на Python 3.9–3.13.
- Новые команды CLI: `verify`, `worlds`, `update-mods`, `check-updates`.

### Изменено

- Настройка «закрывать лаунчер после запуска игры» действительно
  закрывает лаунчер; перед запуском выполняется проверка зависимостей и
  предупреждения выводятся в консоль.

### Исправлено

- `InstanceConfig.load` при отсутствии имени в `instance.json` берёт имя
  каталога, а не значение по умолчанию.

## [1.1.0] — 2026-10-19

### Добавлено

- **Ресурспаки и шейдеры** — поиск на Modrinth и установка в правильные
  каталоги: `resourcepacks/` и `shaderpacks/`.
- **Обновление модов** — лаунчер запоминает, откуда и какой версии
  установлен каждый проект (`installed.json`), проверяет свежие версии и
  обновляет их одним нажатием. Состояние «выключен» сохраняется, а
  удалённые вручную файлы автоматически убираются из индекса.
- **Обновление модпаков** — проверка новой версии сборки и обновление «на
  месте»: файлы новой версии кладутся поверх старых, а исчезнувшие
  удаляются; загрузчик и версия игры обновляются автоматически.
- **Экспорт и импорт экземпляра** — сохранение сборки в `.zip` и перенос
  её на другую машину, а также **резервная копия миров** (`saves/`).
- **Фильтр по установленным модам** и **сортировка таблиц** кликом по
  заголовку столбца (повторный клик меняет направление).
- **Поиск дубликатов модов** (одинаковый mod id).
- **Отчёт о падении игры** теперь показывается в интерфейсе: при
  аварийном завершении лаунчер предлагает открыть папку `crash-reports`.

### Изменено

- При поиске шейдеров и ресурспаков больше не применяется фильтр по
  загрузчику — раньше такие запросы почти всегда возвращали пустой
  список.
- Страница «Экземпляры» получила кнопки экспорта, импорта, резервной
  копии миров и проверки обновлений.

### Удалено

- Мёртвый код и неиспользуемые настройки: около тридцати функций, полей и
  импортов, оставшихся от ранних версий.

## [1.0.0] — 2026-10-19

Первый публичный выпуск.

### Добавлено

- **Версии Minecraft** — полный список Mojang: релизы, снапшоты, старые
  беты и альфы. Установка клиента, библиотек и ресурсов одной кнопкой.
- **Загрузчики модов** — Fabric, Quilt, Forge и NeoForge. Forge и NeoForge
  ставятся официальными installer-jar'ами, как в официальном лаунчере.
- **Аккаунты** — Microsoft (вход по коду устройства, device-code flow),
  офлайн-профили и Ely.by (Yggdrasil).
- **Моды с Modrinth** — поиск, установка, включение и выключение модов
  прямо в экземпляре, импорт `.jar` из файлов. Иконки проектов в списке.
- **Модпаки** — установка `.mrpack` (Modrinth) из файла или по названию,
  с автоматической установкой нужного загрузчика и версии игры.
- **Экземпляры** — отдельный «домашний» каталог для каждой сборки: свои
  моды, миры, настройки и версия. Копирование, переименование, удаление.
- **Профили JVM** — «Хромбук» (экономный), «Сбалансированный»,
  «Производительность», «Ванилла без модов» и свой набор аргументов.
- **Авто-подбор Java** — нужная версия JRE находится локально или
  скачивается с Adoptium под архитектуру машины.
- **Экономия диска** — общие библиотеки и ресурсы для всех экземпляров,
  одинаковые jar'ы связываются жёсткими ссылками; общие рантаймы Java.
- **Графический интерфейс** (tkinter) с тёмной и светлой темой, ленивой
  загрузкой страниц и живой консолью игры.
- **Командная строка** — `gui`, `info`, `doctor`, `versions`, `install`,
  `instances`, `create`, `launch`, `accounts`, `mod-search`,
  `modpack-install` и другие.
- **Диагностика** — команда `doctor` проверяет каталог данных, Java и
  доступ к серверам Mojang и Modrinth.
- **Дистрибутивы** — самораспаковывающийся установщик (без root) и
  пакет `.deb`; собираются скриптом `packaging/build.sh`.

### Известные ограничения

- Пакеты CurseForge напрямую не поддерживаются: используйте версии для
  Modrinth (`.mrpack`) или ставьте моды по одному.
- Интерфейс и сообщения — только на русском языке.
- Иконки проектов Modrinth отображаются, только если они в формате PNG;
  webp/jpeg пропускаются без ошибки.
